Amma Wallet — Privacy Policy

Effective date: March 15, 2026 | Last updated: March 16, 2026

1. Introduction

Amma Wallet ("we", "our", "us") is a cryptocurrency wallet application that operates on the Stellar network. This privacy policy describes how we collect, process, store, and share user data across our web application (ammawallet.com), Chrome browser extension, and mobile application. By using any of our products, you agree to this policy.

2. Data Collection

We collect the following categories of user data:

Data TypeWhat We CollectPurpose
Account InformationEmail address, first name, last nameAccount creation and identification
Authentication DataPassword (stored as bcrypt hash only)Secure login to your account
Wallet DataWallet name, public key, encrypted secret keyWallet management and cross-device synchronization
User PreferencesLanguage preference, network selection (testnet/mainnet)Personalized user experience

Data we do NOT collect: browsing history, location data, health information, personal communications, keystrokes, mouse movements, or any data from other websites or applications.

3. Data Processing

3.1 Account Authentication

When you register, your password is hashed using bcrypt before storage. We never store or process plaintext passwords. Authentication is managed via JSON Web Tokens (JWT) that expire after a set period.

3.2 Wallet Encryption

Your wallet secret key is encrypted on your device using AES-256-GCM encryption with a key derived from your PIN via PBKDF2 (600,000 iterations). Only the encrypted blob is transmitted to and stored on our server. We never have access to your unencrypted private key or your PIN. Decryption happens exclusively on your local device.

3.3 Blockchain Interactions

When you send transactions, swap tokens, or view balances, your browser or app communicates directly with public Stellar network endpoints. Transaction data is recorded on the public Stellar blockchain and is not stored on our servers.

4. Data Storage

4.1 Server-Side Storage

Your account information and encrypted wallet data are stored on a secure server located in a data center with physical and network security measures. The database uses PostgreSQL with encrypted connections.

4.2 Client-Side Storage

The Chrome extension stores authentication tokens and encrypted wallet data in the browser's local storage (chrome.storage API). The mobile app uses secure storage (iOS Keychain / Android Keystore) for secret keys. The web application uses browser localStorage for session tokens.

4.3 Data Retention

We retain your data for as long as your account is active. If you delete your account, all associated data (account information, wallet data, preferences) will be permanently removed from our servers within 30 days.

5. Data Sharing

We do not sell, rent, or trade your personal information to any third party.

We share data only with the following third-party services, solely to provide core wallet functionality:

ServiceData SharedPurpose
Stellar Horizon API (stellar.org)Public key, transaction dataBlockchain interactions (balances, transactions, account info)
StellarExpert API (stellar.expert)No user data — public token queries onlyToken metadata, ratings, and market information

No personal information (email, name, password, or encrypted keys) is ever shared with these services. Only your public wallet address is used for blockchain queries, which is inherently public on the Stellar network.

We do not use your data for:

— Advertising or marketing purposes
— Credit assessment or lending decisions
— Profiling or behavioral tracking
— Any purpose unrelated to providing wallet functionality

6. User Rights

You have the right to:

— Access your personal data by viewing your account settings
— Correct your personal data by updating your profile
— Export your wallet secret key at any time to maintain control of your funds
— Delete your account and all associated data by contacting us
— Withdraw consent by ceasing use of our products and requesting account deletion

7. Security

We implement the following security measures: HTTPS encryption for all data in transit, bcrypt password hashing, AES-256-GCM client-side encryption of private keys, PBKDF2 key derivation with 600,000 iterations, JWT-based authentication with token expiration and refresh, and server-side firewall protection.

8. Children's Privacy

Amma Wallet is not intended for use by individuals under the age of 18. We do not knowingly collect data from minors.
